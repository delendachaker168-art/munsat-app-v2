# منصت (MUNSAT)

تطبيق مراسلة صوتية خفيف. هذا المستودع هو النسخة المستقلة الجديدة.

## المتطلبات
- Node.js LTS
- Expo CLI عبر npx

## التشغيل
```bash
npm install
npx expo start
```

## إعداد Supabase
أنشئ ملف `.env` محليًا اعتمادًا على `.env.example`. لا ترفع مفاتيح سرية إلى GitHub.

## قواعد التسجيل الصوتي
- مدة التسجيل الواحد: دقيقتان كحد أقصى، ثم الإرسال التلقائي.
- التخزين السحابي: حذف التسجيل بعد 3 أيام.
- النسخة المحلية لدى المستلم: حذف بعد 3 أشهر.
