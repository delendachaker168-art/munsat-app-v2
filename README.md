# منصت (MUNSAT)

تطبيق مراسلة صوتية خفيف مبني باستخدام Expo Router وReact Native وSupabase.

## الموجود حاليًا
- إنشاء الحساب وتسجيل الدخول بالبريد وكلمة المرور.
- ملف شخصي باسم ظاهر ونبذة قصيرة وصورة شخصية قابلة للتغيير والحذف.
- البحث عن المستخدمين وإرسال طلبات الصداقة وقبولها أو رفضها وإزالة الصديق أو حظره، مع منع تكرار التخصيص.
- خمس خانات ثابتة لتخصيص الأصدقاء.
- تسجيل صوتي بجودة اقتصادية، بحد أقصى دقيقتين، مع إرسال تلقائي عند بلوغ الحد.
- الرسائل الصوتية محفوظة في مساحة خاصة، والاستماع إليها داخل التطبيق.
- تنزيل الرسائل الواردة على جهاز المستلم والاحتفاظ بها محليًا حتى 90 يومًا.
- حذف النسخ السحابية بعد 72 ساعة عبر مهمة تنظيف مجدولة كل ساعة في Supabase.
- حذف الحساب نهائيًا من داخل التطبيق مع إزالة ملفاته ورسائله وعلاقاته.
- إشعارات داخل التطبيق لطلبات الصداقة والرسائل الجديدة، مع اسم المرسل وتعليم الإشعار كمقروء.
- أوامر صوتية محلية عبر Vosk: «محادثة واحد» إلى «محادثة خمسة»، مع تأكيد قبل بدء التسجيل.
- خدمة Android أمامية بإشعار دائم لإبقاء الاستماع الصوتي نشطًا عند الانتقال إلى الخلفية، بعد منح إذن الإشعارات.
- تنزيل نموذج التعرف العربي مع عرض التقدم والسرعة والوقت المتبقي، ودعم الاستكمال بعد الإيقاف.

## المتطلبات والتشغيل
- Node.js LTS
- تثبيت الاعتماديات: `npm install`
- تشغيل التطوير: `npx expo start`

## إعدادات البناء
- مكتبات Vosk وفك الضغط والخدمة الأمامية إضافات أصلية؛ يلزم بناء EAS جديد لتضمينها، ولا يعمل التعرف الصوتي داخل Expo Go.
- ملف `eas.json` يحتوي ملفي preview وproduction.
- ملف `app.json` يحدد معرّف Android: `com.delendasmartsolutions.munsat`، وأيقونة التطبيق في `assets/icon.png`.
- تم ربط المستودع بمشروع Expo الحالي عبر `owner` و`extra.eas.projectId`، دون بدء أي بناء تلقائي.

## Supabase
العميل يستخدم عنوان المشروع ومفتاح Publishable المخصص للتطبيق. لا تضع أبدًا مفتاح `service_role` أو أي سر خادمي في التطبيق.

## نموذج التعرف الصوتي
- النموذج العربي التونسي الصغير من Vosk، بحجم تنزيل يقارب 158 MB.
- يُنزّل إلى مساحة التطبيق ويُفك ضغطه محليًا؛ لا تُرسل التسجيلات أو أوامر التعرف إلى خادم.
- دقة اللهجة الجزائرية تحتاج إلى تجربة ميدانية، والنموذج الديناميكي ميزة تجريبية في مكتبة Vosk.

## ملاحظات الاحتفاظ بالرسائل
- التخزين السحابي: 3 أيام.
- النسخة المحلية على جهاز المستلم: 3 أشهر، مع تنظيف دوري عند فتح شاشة الرسائل.
- الحد الأقصى للتسجيل: 120 ثانية.
